Chave de API (Anthropic)

Para o app analisar fotos de mesa fora do Claude.ai (site publicado ou APK), ele precisa de uma chave de API própria. Crie a sua gratuitamente em console.anthropic.com → API Keys. A chave fica salva só neste aparelho, nunca é enviada para outro lugar além da própria Anthropic.

Dica: para instalar no celular, abra este link no navegador e use "Adicionar à tela de início" (Android/Chrome) ou "Adicionar à Tela de Início" no menu Compartilhar (iPhone/Safari).
